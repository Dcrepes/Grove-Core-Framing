# What Holds Your Home Together

A one-page guide for Realtors that explains, in plain English, the six steel connectors (anchors, ties, straps and structural screws) that tie a Lennar home together from the slab to the roof.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, named `Grove-Core-Framing`.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the root of the repo. You can drag and drop them on the repo page using **Add file > Upload files**.
3. Go to **Settings > Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, the site is live at https://dcrepes.github.io/Grove-Core-Framing/.

## Updating

Edit `index.html` and commit the change. GitHub Pages republishes automatically within a few minutes. The QR code keeps working as long as the repo name and username stay the same.
